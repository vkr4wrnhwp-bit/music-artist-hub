# Asset manifest

Everything in the film, and where it came from. No third-party stock, no
licensed music, no external imagery.

## Footage

| Asset | Origin | Licence |
|---|---|---|
| `recordings/0*.webm` / `.mp4` | Playwright driving the shipping MASTERCLIP OS build against a throwaway database | Own product |
| Video inside the review grid | Generated live by the application's ffmpeg sandbox provider during capture | Own product |

## Audio

| Asset | Origin | Licence |
|---|---|---|
| `audio/score-hero.wav` | Generated by `@masterclip/ai-audio` `synthesizeWav()` — the product's own synthesis engine | Own product |
| `audio/score-sales.wav`, `score-social.wav` | Trimmed from the hero bed so all cuts share one musical identity | Own product |

Treatment: 2-band mix (pad + sub-pulse at 0.22), low-pass 5.2 kHz, gentle 3:1
compression, `loudnorm I=-19 TP=-1.5 LRA=9`, fades. Measured mean −20.1 dBFS,
peak −7.3 dBFS — no clipping, and headroom for a voiceover if one is added later.

## Typography

| Face | Use | Licence |
|---|---|---|
| Archivo 400/600/700 | Display, headlines, metric | SIL Open Font License 1.1 |
| IBM Plex Mono 400/500/600 | Labels, data, eyebrows | SIL Open Font License 1.1 |

Both bundled into `public/fonts/` so renders are reproducible offline. The
application itself uses system font stacks, so there was no brand font to
honour; these were chosen as premium substitutes.

## Colour

Every value in `src/config/brand.ts` is copied verbatim from the application's
own `apps/web/src/styles.css`. No colour in the film was invented.

## Not used

No stock footage, no stock photography, no third-party music, no icon packs,
no AI-generated imagery, and no logo assets beyond the product's own wordmark
set in Archivo.
