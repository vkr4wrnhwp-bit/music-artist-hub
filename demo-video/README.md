# Product demo film system

A reusable engine for turning a working web application into a premium product
film. Playwright drives and records the real product; Remotion composes the
film; ffmpeg finishes it.

Built for MASTERCLIP OS, but the product-specific parts are isolated to two
config files and one capture script.

```
demo-video/
  README.md
  package.json           remotion + react
  remotion.config.ts     browser + encoder settings
  storyboards/           product brief, timed storyboard  ← read these first
  scripts/
    capture-server.mjs   boots the app for capture (throwaway DB, no keys)
    capture.mjs          drives and records the hero workflow
    finish.mjs           mux audio, thumbnails, probe report
  src/
    config/brand.ts      ← BRAND TOKENS. Change this per product.
    config/film.ts       ← SCENES + COPY. Change this per product.
    config/fonts.ts      bundled typefaces
    components/          reusable film language
    compositions/Film.tsx one parameterized composition, four deliverables
  public/
    fonts/  recordings/  assets Remotion serves at render time
  recordings/            raw capture (webm) + normalized mp4
  audio/                 generated score
  renders/               deliverables + thumbnails
```

## Running it

```bash
# 1. build the app's web bundle (once)
cd ../masterclip-os && pnpm -F @masterclip/web build && cd ../demo-video

# 2. boot the app for capture — throwaway DB, sandbox mode, no provider keys
node scripts/capture-server.mjs &

# 3. record the workflow (~4 min: it really renders a batch)
DEMO_PORT=4410 node scripts/capture.mjs

# 4. normalize captures to mp4 and publish them to Remotion
cd recordings && for f in *.webm; do
  ffmpeg -y -i "$f" -vf "fps=30,format=yuv420p" -c:v libx264 -preset slow -crf 17 -an "${f%.webm}.mp4"
done && cd .. && cp recordings/*.mp4 public/recordings/

# 5. render
npx remotion render src/index.ts HeroLandscape   renders/hero-landscape.mp4
npx remotion render src/index.ts SalesLandscape  renders/sales-landscape.mp4
npx remotion render src/index.ts SocialVertical  renders/social-vertical.mp4
npx remotion render src/index.ts CleanScreenOnly renders/clean-screen-only.mp4

# 6. finish: score, thumbnails, probe report
node scripts/finish.mjs
```

`npx remotion studio src/index.ts` gives a live preview while editing copy.

## Retargeting to another application

The engine is deliberately split so a new product needs three edits, not a
rewrite.

| Change | File | What it holds |
|---|---|---|
| Brand | `src/config/brand.ts` | colours, fonts, type scale, product name, promise, CTA |
| Story | `src/config/film.ts` | scene list, durations, action labels, value lines, metrics |
| Journey | `scripts/capture.mjs` | the clicks that produce the footage |

`src/components/` and `src/compositions/` should not need touching. The
composition is parameterized — `order`, `durations`, `clean` and `vertical`
props produce all four deliverables from one component tree, so a fifth cut is
a `<Composition>` entry, not new code.

**Colours are copied verbatim from the application's own stylesheet.** That is
the rule that keeps the film from drifting away from the product: when the app
restyles, re-copy the tokens rather than eyeballing a match.

## The copy system

Every scene carries two levels and no more:

- **ACTION LABEL** — what is happening now, 2–7 words.
- **Value line** — why the customer cares, 6–18 words.

The words never narrate the cursor. "Click the Analytics tab" is a caption; the
film says what the product just did for you and why that matters. Reading time
is never under ~2.5s.

## Honesty rules baked into this system

These are not stylistic preferences; they are the difference between a demo and
a misrepresentation.

1. **The footage is the real product.** Playwright drives the shipping build
   against a real database and a real worker. Nothing is mocked up in Remotion.
2. **Sandbox is disclosed on screen for the whole film.** The application's own
   banner stays visible, and the film adds its own persistent note.
3. **Every number quoted was read off the running app**, not invented for the
   edit.
4. **No claim the product cannot support.** MASTERCLIP has never run a paid
   provider, so the film sells the system and never the generated pixels.

## Audio

The score is generated by the product's own synthesis engine
(`@masterclip/ai-audio`), so it is owned outright with no licensing question —
and it is literally the product scoring its own trailer. See
`../masterclip-os/scratch/score.ts`.

The film is built to be fully comprehensible **muted**; the music carries pace,
never meaning. There is no voiceover: no licensed TTS was available in the build
environment, and a muted-legible film was the stronger requirement anyway.

## Known environment quirks

- This sandbox's Chromium has old headless mode removed, which Remotion's
  launcher requests. `remotion.config.ts` points at the `chrome-headless-shell`
  binary beside it — the supported standalone implementation of that mode. On a
  normal machine, unset `REMOTION_BROWSER_EXECUTABLE`.
- Playwright records at viewport size, so 1920×1080 source caps the master at
  1080p. For a 4K master, capture stills at `deviceScaleFactor: 2` and compose
  push-ins over those instead of video.
