{# Design system v1 typefaces. Archivo variable carries display and text from one file - its width axis is what gives headings an expanded, institutional stance (the bank half of "street banker") while the normal width stays tight and legible in dense tables. Machine values - timecode, DMX address, ISRC, money, deltas - are Archivo with tabular numerals: the owner ruled out monospace on 2026-09-13 ("it reads as typewriter text"). display=swap because a slow font must never blank a page a light operator is reading mid-show. The fallback stacks live in the Tailwind theme (fontFamily) and in --sb-text / --sb-mono. Included by base.html and by every template that carries its own ; there is no third place to add it. #}
