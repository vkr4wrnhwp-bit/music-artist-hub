{#- The Rack chain as knob-rendered modules, per the owner's mockup. Every needle position is computed server-side from the REAL saved preset - the same JSON the Rack loads - using the cos/sin Jinja globals the homepage's VU meters already use. Nothing here is decorative state: a knob at 2 o'clock is at 2 o'clock because that is what the artist saved. Read-only by design, and each module says so the useful way: "edit" deep links into that module's own unit in the Rack (#sb01..#sb08 anchors), where the DSP engine actually lives. A knob you could drag here would either lie (no engine loaded to hear it) or fork the state two ways. The power LED is truthful too: lit only when the module is doing something to the signal - a tube at mix 0 is dark, a compressor at 1:1 is dark - because a lit lamp on an inert module is a tiny lie that compounds at 2 a.m. before a deadline. -#} {% macro knob(label, value, unit, lo, hi) -%} {%- set span = (hi - lo) if hi != lo else 1 -%} {%- set frac = ((value - lo) / span) -%} {%- set frac = 0.0 if frac < 0 else (1.0 if frac > 1 else frac) -%} {%- set rad = (frac * 270 - 135) * pi / 180 -%} {{ value }}{{ unit }} {{ label }} {%- endmacro %} {% macro module(tag, title, active, anchor, rack_href) -%}
