# SHOW ME — BUILT (NC analyzer)

Every finding, feed proposal and finish-protected region on the NC
analyzer carries SHOW ME. It is never a text modal: clicking it frames
the backplot on the finding's own segments (bounding box + context
margin), highlights them amber with everything else dimmed, and scrolls
the block-synced code viewer to the source line, highlighted. Esc or
Clear restores the full-program frame.

The same selection drives both scenes — one source-line range, two
views — so "where is this" has one answer everywhere.
