# Lathe workholding

LatheWorkholding table: chucks, collets, soft jaws, centers, mandrels.
The demo 8" chuck deliberately carries NO clamp force — the grip
analysis returns UNKNOWN and names the missing input; recording the
real hydraulic setting (audited, on the workspace) is what moves the
gate. Grip analysis inputs: grip diameter/length, jaw material,
serration, clamp force, stickout, chuck RPM limit vs programmed max.
Verdicts PASS/REVIEW/FAIL/UNKNOWN, all DEVELOPMENT ANALYSIS.
Stickout: L/D guidelines 4:1 (review) / 8:1 (fail) unsupported,
tailstock-aware. Part-off: tailstock-engaged = FAIL (blade pinch),
overhang ratio, drop management honestly stated.
